# ProjectRecord Demo

เดโมแยกอิสระใน `demo/` ไม่ต้องใช้ API key หรือ service ภายนอกของ repository

## เปิดใช้งาน (Windows PowerShell)

```powershell
cd demo
npm.cmd install --cache .npm-cache --no-audit --no-fund
npm.cmd run dev
```

เปิด http://127.0.0.1:5173 แล้วเลือก **ลองใช้งานเดโม**

## สิ่งที่ทำได้

- หน้าหลัก สมัครสมาชิก และเข้าสู่ระบบแบบจำลอง
- Dashboard ที่คำนวณจากข้อมูลจริงในเดโม
- สร้าง/แก้ไข/ลบ/เก็บเข้าคลังโปรเจ็ค พร้อมเพิ่มงานย่อยหลายรายการ
- งานมีสถานะ ความสำคัญ ช่วงเวลาทำงาน กำหนดส่ง และเวลาเตือน
- To-do list พร้อมค้นหา กรองตามโปรเจ็ค วันนี้ งานเลยกำหนด และสถานะ
- ปฏิทินเดือน/สัปดาห์ เลื่อนช่วงเวลา คลิกวันที่ ดูแผน เพิ่ม/แก้ไขงาน
- ทุกหน้าใช้ข้อมูลเดียวกัน และข้อมูลไม่หายเมื่อรีเฟรช
- การแจ้งเตือนในแอป มีอ่านแล้ว/ยังไม่อ่าน เปิดกลับไปยังงาน เลื่อนอีก 10 นาที และการจำลองเวลา
- เตือนเบราว์เซอร์ได้เมื่อเบราว์เซอร์รองรับและผู้ใช้อนุญาต
- Responsive, keyboard focus, dialogs, error/empty states และการยืนยันก่อนลบ

## ขอบเขตของเดโม

**ไม่มีระบบยืนยันตัวตนจริง** เก็บเฉพาะชื่อ อีเมล และ ID ของบัญชีจำลอง ไม่เก็บหรือตรวจรหัสผ่าน รับรหัสผ่านใดก็ได้ที่มีอย่างน้อย 6 ตัวอักษรตอนเข้าสู่บัญชีที่ลงทะเบียนแล้ว ให้ใช้ข้อมูลสมมติเท่านั้น

ข้อมูลอยู่ใน `localStorage` โดยแยกตามบัญชีบนเบราว์เซอร์นี้ ไม่ซิงค์ข้ามอุปกรณ์ และไม่ใช่การแยกสิทธิ์ที่ปลอดภัยสำหรับระบบจริง `sessionStorage` เก็บเฉพาะโปรเจ็คที่กำลังเปิดอยู่

เวลาแสดงและรับข้อมูลเป็น Asia/Bangkok วันเวลาของงานจัดเก็บเป็น UTC ส่วนวันเริ่มและสิ้นสุดโปรเจ็คจัดเก็บเป็นวันที่ล้วน

รายการเตือนตรวจทุก 10 วินาทีขณะเปิดเว็บ และตรวจเมื่อกลับมาที่แท็บ/เข้าสู่ระบบ เบราว์เซอร์อาจชะลอ timer เมื่ออยู่เบื้องหลัง เมื่อปิดแท็บแล้วจะไม่ส่งการเตือนจนกลับมาเปิดเว็บ ต้องเพิ่ม server scheduler และ Web Push/อีเมลสำหรับการใช้งานจริง Mobile บางเบราว์เซอร์ไม่รองรับ `new Notification`; การแจ้งเตือนในแอปยังทำงานได้

งานสำเร็จและงานในโปรเจ็คที่เก็บเข้าคลังไม่ส่งการเตือน การแก้กำหนดเวลาอัปเดตรายการเตือน การลบงานลบประวัติของงานนั้นด้วย การจำลองเตือนติดป้าย “จำลองเวลา” และไม่เปลี่ยนรายการเตือนจริง

ฟอนต์ Noto Sans Thai และ DM Sans รวมอยู่ในไฟล์แอปผ่าน Fontsource ไม่มีการเรียกฟอนต์หรือ API ภายนอกขณะใช้งาน หลังติดตั้ง dependencies แล้วสามารถเปิดเดโมโดยไม่ต้องใช้อินเทอร์เน็ต

## สคริปต์

```powershell
npm.cmd run build
npm.cmd run preview
npm.cmd test
```

`build` ตรวจ TypeScript และสร้างไฟล์ใน `demo/dist/` `preview` เปิดที่ http://127.0.0.1:4173

ชุดทดสอบใช้ Playwright กับ Google Chrome ที่ติดตั้งในเครื่องผ่าน `channel: 'chrome'` หากไม่มี Chrome ให้ติดตั้ง หรือเปลี่ยน config เป็น browser ที่มีในเครื่อง ผลทดสอบและ trace อยู่ใน `demo/test-results/`

## ลำดับนำเสนอ

1. อธิบายแนวคิดจากหน้าหลัก แล้วเปิดเดโม
2. สร้างโปรเจ็คพร้อมงานย่อย 3 งาน และเวลาเตือนในอนาคต
3. ดูงานในปฏิทินและ To-do list แล้วแก้เวลา
4. กดจำลองแจ้งเตือนในรายละเอียดงาน และเปิดงานจากกระดิ่ง
5. ติ๊กงานสำเร็จ ดูความคืบหน้าบน Dashboard
6. รีเฟรชหน้าเพื่อยืนยันการบันทึกข้อมูล

## โครงสร้าง

`src/App.tsx` — หน้าจอและการใช้งาน

`src/model.ts` — ข้อมูล วันที่ ความคืบหน้า และการเตือน

`src/style.css` — รูปแบบหน้าจอและ responsive

`tests/demo.spec.ts` — ทดสอบเส้นทางใช้งานครบวงจร

`vite.config.ts`, `tsconfig.json`, `playwright.config.ts` — ตั้งค่าภายในเดโม

ทั้งหมดแยกจาก Python service และต้นแบบเดิม ต่อ Supabase ในอนาคตได้โดยเปลี่ยนชั้นจัดเก็บข้อมูลและบัญชี ไม่ใส่ Secret key ลงใน frontend
